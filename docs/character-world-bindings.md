# 角色与世界书资源

Agent RP 将 SillyTavern 角色卡视为交换格式，而不是内部资源所有权模型。导入带有 `character_book` 的 PNG、JSON 或 CHARX 时，Host 保留原始角色卡字节，同时生成一个独立 World Info 资产和一条角色世界绑定。

## 持久资源

- 角色资产保存在角色库中，内容寻址编号以 `card-` 开头。原始文件始终可以原样读取。
- World Info 资产保存在世界书库中，内容寻址编号以 `world-info-` 开头。两张角色卡带有相同世界书内容时复用同一个资产。
- 角色世界绑定单独保存。主世界与附加世界分别记录来源；从角色卡拆出的主世界标记为 `embedded-import`，玩家在资源中心保存的完整组合标记为 `user-bound`。

无内置世界书的角色也会保存一条主世界为空的绑定记录。该记录表示角色已经迁移，避免 Host 在每次启动时重复解析旧资产。

## 导入与迁移

新的角色导入通过角色库统一完成拆分。Host 启动时只处理没有绑定记录的旧角色，保留原始文件和角色编号。拆出的 World Info JSON 保留角色卡世界书及条目的未知字段，并补充 SillyTavern 独立世界书所需的字段名。

世界书仍被角色绑定时不能从世界书库删除。永久删除已收纳角色会移除绑定，但不会自动删除独立 World 资产；仍需要的世界不会因角色生命周期而消失。

## 编辑默认世界组合

资源中心的角色列表提供“世界组合”编辑器。主世界可以更换或清空；附加世界可以选择、移除并调整顺序。一个角色最多绑定 16 本世界书，主世界和附加世界之间不能重复。已收纳的角色需要先恢复再编辑。

已经开始的会话不会随角色的默认世界组合继续变化。「会话设置 → 世界书」可以从资源中心添加一份 World Info 当前快照，也可以导入新的 JSON 文件；已经由角色或会话加载的同一资源不会再次列入选择器。资源中心条目后续修改或移除不会改写会话快照。

编辑器按完整组合保存并检查当前修订；同一角色已在另一个页面保存时，旧页面不会覆盖新结果。Host 会先确认角色状态、全部 World Info 资产、数量和重复项，再原子替换绑定文件。

## Session 与导出

新建角色 Session 会先保存角色快照，再按主世界、附加世界的稳定顺序保存角色绑定的 World 快照。它们标记为角色侧资源；玩家另外选择或默认启用的世界标记为体验侧资源。启动器会排除已经绑定的 World 编号，防止同一本书以两种身份重复进入会话。

世界召回、MVU 初始化与更新规则、回合规划和浏览器投影读取同一组 Session World 快照。核心运行时中的角色不再携带 `card.lorebook`。旧 Session 和直接导入流程没有角色侧 World 快照时，兼容适配器仍可读取当时保存在角色卡快照中的内置世界书；该回退不会用于新建的角色库会话。

“导出当前版本”会把当前绑定的主世界转换回对应版本的 SillyTavern `character_book`；附加世界继续保持独立，不会被合并进单本交换字段。主世界为空时，当前版本不包含 `character_book`。“导出原始文件”始终返回导入时的 PNG、JSON 或 CHARX 字节，不受绑定和当前版本导出影响。
